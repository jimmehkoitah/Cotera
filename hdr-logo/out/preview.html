Cotera HDR logo — device test

Open this on the device you want to check. The white strip beside each image is a plain #ffffff pixel — SDR white. If HDR is working, the mark reads brighter than that strip.

checking display capabilities…
If every image looks identical to the SDR control, this display has no HDR headroom, the browser is ignoring the tagging, or the OS is in a mode that clamps HDR. That is the expected outcome on most desktop monitors.
