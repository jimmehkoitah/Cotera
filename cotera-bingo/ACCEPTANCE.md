# Rehearsal for the hosted game

Use the published practice URL with `?mode=personal`, never event mode for test attendees. Localhost is only for this computer.

1. Scan the practice QR on iPhone and Android. The welcome screen must offer Play Bingo and Share three problems.
2. Choose Play Bingo. Enter name/company/contact/consent first, then select a role. Check six readable square tiles.
3. Follow the caller on the main screen and the phone. A tile stays locked until called. Tap three called matches; Bingo must open a saved prize code. Each role receives three calls by 2:41 of the three-minute round. Earlier calls remain selectable until the round ends.
4. On a second phone, choose Share three problems and a different contact/role. Select exactly three, submit, and check the saved code. No Bingo play is needed.
5. Have the Bingo winner also submit three real problems. The same code must remain; no second kit. In booth controls, game matches and reported problems must be clearly distinguished.
6. Close and reopen the original browser. Identity, selected path, reported problems and prize code should return. Current-round matches reset at round rollover; prizes do not. Do not use private browsing for the event.
7. Mark a practice code collected in booth controls and verify the phone updates. Repeating collection must not issue or consume another kit.
8. Pause Bingo, then resume. The caller and remaining time freeze while paused. The direct path stays open. Schedule a panel restart and check its message/countdown on both screen and phone; the next round starts once. Test a new player joining during the pause.
9. Add a written problem. Confirm it stays private until approved and then appears without a name/contact. Hide it again. Notes never earn another kit.
10. Turn off phone connectivity, restore it, and retry a pending action. Check reconnection without duplicate matches or prizes. Test venue Wi-Fi and cellular service.
11. Check the display at the actual screen size and QR scanning distance. No TV is required; calls also appear on phones. People with closed phones need a verbal announcement; there is no background push.
12. Download the private CSV. It must include registrations (even before play), Bingo participation, explicit reported problems, written notes, contacts, role, codes and collection status. Check the real kit-stock limit before opening event mode.
